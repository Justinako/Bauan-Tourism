Discover Bauan — Tourism Web Application
Welcome to the newly updated Discover Bauan tourism platform! This repository contains a fully revamped, high-performance web application designed to showcase the pristine beaches, marine sanctuaries, culture, and attractions of Bauan, Batangas.

✨ Key UI & Feature Updates
Atmospheric Glassmorphic Navbar: Redesigned with a full-width background, smooth blur effects (backdrop-filter), and distinct logo branding.

Interactive Slide-Out Mobile Drawer: Enhanced mobile navigation featuring a responsive hamburger menu and smooth slide-out transition overlay.

Live GPS Resort Navigation: Integrated location-based routing tools allowing travelers to calculate live distances and open turn-by-turn directions directly to Bauan resorts via Google Maps.

Interactive Itinerary Generator: Custom trip planners tailored for day trips or weekend getaways based on traveler preferences (adventure or relaxation).

Multi-Language Support: Instant language switcher between English and Tagalog.

Community Review & Photo Uploads: Fully responsive customer testimonial and submission portal with image-upload simulations.

AI Chatbot Assistant: Built-in Gemini-powered assistant widget ready to answer traveler questions in real-time.

🚀 Quick Start
Clone or download this repository.

Ensure you have the following core files in your project directory:

index.html (Main entry point with updated glassmorphic navigation and UI styles)

style.css (Stylesheet for layout and components)

script.js (Core logic for localization, weather, GPS routing, and itinerary generation)

Open index.html in any modern web browser or run it via a local development server (e.g., VS Code Live Server).
